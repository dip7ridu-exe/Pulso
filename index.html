Adicionar playlist

Cole o link de uma playlist do YouTube ou Spotify. Ela ficará salva neste navegador.

YouTube: links com list=. Spotify: open.spotify.com/playlist/... ou spotify:playlist:...

Conectar o Google

Para mostrar automaticamente as playlists da sua conta, configure um Client ID do Google. Seus links adicionados funcionam mesmo sem isso.

1Crie um projeto no Google Cloud e ative a YouTube Data API v3.
2Configure a tela de consentimento e crie um ID do cliente OAuth do tipo Aplicativo da Web.
3Adicione https://usuario.github.io às origens JavaScript autorizadas. Em modo de teste, adicione seu e-mail como usuário de teste.
Alternativa ao login para listar faixas de playlists públicas. Restrinja a chave ao endereço do seu site e à YouTube Data API v3.
O Client ID fica salvo apenas neste navegador. A autorização usa a janela oficial do Google; a senha nunca passa por este site.
